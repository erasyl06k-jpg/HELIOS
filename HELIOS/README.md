# E02: проверка цикла разгибания локтя

Нейтральный результат: «выполнено» или «проверьте инструкцию». Медицинских советов инструмент не даёт.

## Запуск демо
1. Если есть видеоинструкция, положите её рядом с файлом под именем `instruction.mp4`. Без неё показывается анимированная схема движения.
2. Запустите локальный сервер: `python -m http.server 8000` и откройте http://localhost:8000/app.html
   (нужен интернет при первом запуске: библиотека и модель MediaPipe Pose загружаются из CDN).
3. Выберите «Камера» или «Загрузить видео» и выполняйте упражнение.
Видео обрабатывается в браузере и никуда не отправляется.

## Как работает
Pose-модель (MediaPipe Pose Landmarker) даёт точки плеча, локтя и запястья. Считается угол в локте,
сигнал сглаживается. Циклы выделяются по чередованию минимум, максимум, минимум (порог разворота 20 градусов).
Для каждого цикла считаются 5 признаков: амплитуда, максимальный угол, минимальный угол, длительность, пиковая скорость.
Решает логистическая регрессия (`model.json`). Если уверенность ниже 0,70, показывается «проверьте инструкцию».
Без `model.json` работает только базовое правило (амплитуда ≥ 90 и максимум ≥ 150 градусов).

## Обучение и метрики
1. Запишите видео добровольцев, прогоните через `app.html`, нажмите «Экспорт циклов» и разметьте файлы.
2. Соберите `data/index.csv` (`path,volunteer_id,label`) и запустите `pip install -r requirements.txt && python train.py`.
3. Скрипт делит выборки строго по `volunteer_id` (с проверкой отсутствия пересечений), подбирает C на validation,
   считает на test balanced accuracy, F1 и матрицу ошибок для модели и для базового правила, пишет `metrics.json` и `model.json`.
Положите `model.json` рядом с `app.html`, и он подхватится автоматически.

Важно: в этой сборке реальных метрик нет, потому что датасета E02 у автора прототипа не было. Числа в отчёт попадут только после запуска `train.py`.
